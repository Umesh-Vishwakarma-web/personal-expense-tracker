\# 💰 Personal Expense Tracker



A simple and user-friendly expense management application built with \*\*Python, Streamlit, SQLite, and Pandas\*\*.



The application allows users to record, manage, filter, analyze, edit, delete, and export their personal expenses through an interactive web interface.



\---



\## 🚀 Features



\- ➕ Add new expenses

\- 📋 View expense history

\- ✏️ Edit existing expenses

\- 🗑️ Delete expenses

\- 📊 View total expenses

\- 🔢 View number of expenses

\- 💰 Calculate average expense

\- 🏷️ Filter expenses by category

\- 📅 Filter expenses by date range

\- 📊 Category-wise spending chart

\- 📈 Monthly spending chart

\- ⬇️ Export filtered expenses to CSV

\- 💾 Store data using SQLite database



\---



\## 🛠️ Technologies Used



\- \*\*Python\*\*

\- \*\*Streamlit\*\*

\- \*\*SQLite\*\*

\- \*\*Pandas\*\*

\- \*\*Matplotlib\*\*
